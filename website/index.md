# Sprint Relay Documentation

Sprint Relay は、小規模な開発チームの会議・仕様・タスク・進捗を Discord と GitHub を中心に管理するサービスです。AI は議事録の整理、計画の提案、技術監査などを支援し、重要な決定は人間が行います。
